# Sentiment Analysis Using LSTM

A machine learning application for analyzing the sentiment of text reviews using a **Long Short-Term Memory (LSTM)** model. This project was developed as part of a Text Mining assignment using a vibe coding approach and deployed as an interactive web application with Streamlit.

## 🚀 Live Demo

Access the deployed application here: **[Sentiment Analysis Review — Streamlit App](https://2702217195-leoranatania.streamlit.app/#analisis-sentimen-review)**

## 🎯 Project Objectives

- Develop a machine learning application for text sentiment analysis.
- Train a sentiment classification model using LSTM.
- Provide an interactive and user-friendly interface for analyzing text reviews.
- Deploy the application using Streamlit so it can be accessed online.

## 📊 Dataset

The dataset used in this project is provided by the following GitHub repository:

- **Dataset:** [data.csv — Text Mining Session 12](https://github.com/rzyunanda/Text-Mining-Session-12/blob/main/data.csv)

The dataset is used as the source of labeled text data for training the sentiment analysis model.

## 🧠 Methodology

This project uses **Long Short-Term Memory (LSTM)**, a type of Recurrent Neural Network (RNN) designed to learn patterns in sequential data, including text.

The general workflow consists of the following steps:

1. Loading the dataset.
2. Preprocessing the text data.
3. Converting text into numerical representations suitable for model training.
4. Training the LSTM model using labeled data.
5. Integrating the trained model into a Streamlit application.
6. Deploying the application online.

## Application Features

The application provides a web-based interface for users to interact with the sentiment analysis system and analyze text reviews.

## Running the Application Locally

To run the application locally:

1. Clone or download the project repository.
2. Install Python and the required dependencies.
3. Install the libraries listed in the project's `requirements.txt` file, if available.
4. Run the main application file using Streamlit:

   ```bash
   streamlit run app.py
   ```

   Replace `app.py` with the actual name of the main Python file if it differs.
